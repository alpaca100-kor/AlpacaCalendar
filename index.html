사용 방법

  1. 상단의 [월별보기] / [1년전체] 탭을 눌러 보기 방식을 전환합니다.
  2. 연도(그리고 월별보기에서는 월)를 직접 입력하거나 ◀ ▶ 버튼으로 원하는 달·해로 이동합니다.
  3. 오늘 / 올해 버튼을 누르면 현재 날짜가 있는 달·해로 바로 돌아갑니다.
  4. 빨간색으로 표시된 날짜는 대한민국 공휴일입니다. PC에서는 마우스를 올리면, 모바일에서는 탭하면 공휴일 이름이 나타납니다.
  5. 토요일은 파란색, 일요일과 공휴일은 빨간색 숫자로 구분되어 표시됩니다.

알아두면 좋은 점

  • 오늘 날짜는 동그라미로 강조되며, 라이트/다크 모드 어디서도 눈에 잘 띄도록 색이 자동으로 바뀝니다.
  • [1년전체] 보기에서는 아래로 스크롤해도 요일(일~토) 머리글이 상단에 고정되어 항상 보입니다.
  • 공휴일 정보는 인터넷에 연결되어 있을 때 자동으로 불러오며, 연결이 없어도 달력 자체는 정상적으로 사용할 수 있습니다.
  • 라이트/다크 테마 선택은 이 브라우저에 저장되어 다음에 다시 열어도 그대로 유지됩니다.
